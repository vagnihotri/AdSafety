Ad Image Policy Moderation System Technical Report

Efficient Image Classification with YOLOv8

This technical report details the development, empirical scaling, and optimization of an automated computer vision pipeline designed to moderate advertisement creatives based on strict community safety guidelines. The main aim of the study is to establish a highly efficient, real-time classifier capable of operating within bounded computing environments (such as Apple Silicon MPS) while accurately distinguishing between severe policy violations (e.g., weapons, explicit content, drugs) and compliant imagery.

Initially, a dual-model approach utilizing a lightweight convolutional neural network (YOLOv8n) alongside a large multimodal vision-language model (Microsoft Florence-2 with LoRA) was considered. However, the operational characteristics of the models were drastically different. While Florence-2 offered deep representational subtlety and contextual understanding, it required significant VRAM footprint resulting in out-of-memory crashes. Consequently, the architecture shifted entirely to the highly efficient YOLOv8n-cls network. Scaled from a baseline dataset to a massive 8,000-image corpus, the convolutional architecture demonstrated extreme computational efficiency, resolving inferences in milliseconds using only 1.44 million parameters, making it the superior choice for production backend deployment.

Experiment Setup

The pipeline was implemented in PyTorch with the ultralytics library utilized for model creation, training, and ONNX export. The core model is YOLOv8n-cls (nano variant), representing a modern, highly optimized convolutional architecture consisting of 30 fused layers. The network accepts three-channel RGB input tensors resized to 224 by 224 pixels. Pretrained weights were leveraged as the starting checkpoint.

Data ingestion was orchestrated using fiftyone and the Hugging Face datasets library. The dataset consisted of 8,000 images, meticulously balanced to 1,000 images across 8 distinct taxonomy classes. The taxonomy included four violation categories (weapons, adult explicit, alcohol/tobacco, drugs/paraphernalia) and four compliant categories. To address edge cases in the drugs_paraphernalia class, both "Pill" and "Syringe" object classifications from OpenImages V7 were aggregated.

The dataset was robustly divided using an 80/10/10 split for Training, Validation, and Testing. To prevent overfitting and ensure structural generalization, rigorous data augmentations were explicitly enforced during training. These included randaugment, rotational shear (degrees=15.0), horizontal flipping (fliplr=0.5), image blending (mixup=0.1), and random patch erasing=0.4.

Inference for the web application was decoupled from PyTorch and executed using onnxruntime with CPU/MPS execution providers. Softmax normalization was applied to the output logits to determine class probabilities, which were subsequently mapped against a threshold matrix (0.85 for Automated Block, 0.50 for Human Review) to yield a final calibrated violation score.

Results Summary

The retraining of the YOLOv8n model on the scaled 8,000-image dataset yielded a highly confident predictive distribution. In empirical testing, edge-case raw images containing syringes and weaponry—which were previously misclassified with low confidence—were accurately flagged. For example, a raw test image of drug paraphernalia yielded a 0.937 violation score, seamlessly pushing the asset into the "Automated Block" queue by correctly aggregating probability vectors across the dangerous categories.

Architecture Comparison

A structural profiling of the YOLOv8n-cls model demonstrates its stark contrast to the initially proposed Florence-2 vision transformer. YOLOv8n-cls utilizes an incredibly constrained footprint: 1,442,566 total parameters, generating approximately 3.3 GFLOPs per forward pass. In contrast, the baseline Florence-2 model requires hundreds of millions of parameters, heavily concentrating compute in multi-head self-attention and dense feedforward projections.

The YOLO architecture's composition of shared localized convolutional kernels and spatial pooling provides strong spatial locality and translation equivariance. This drastically reduces the parameter memory size, allowing the entire model, gradients, and optimizer states to easily fit within standard mobile or edge-device RAM.

Technical Analysis

The experiment underscores the efficiency benefits of hierarchical downsampling over isotropic attention in resource-limited environments. YOLOv8n gradually enhances spatial context while reducing resolution, concluding in a highly precise probability distribution across the 8 distinct classes.

Furthermore, memory constraints were explicitly managed. During initial testing, the Apple Silicon MPS backend faced severe memory fragmentation when handling parallel data loaders and the massive Florence-2 model. By eliminating the vision-transformer branch, enforcing workers=0 for the data loader, and introducing strict batch sizing (batch=2), the pipeline stabilized completely.

Deployment latencies indicated that onnxruntime executing the exported YOLOv8n .onnx graph vastly outperforms native PyTorch inference. The execution is nearly instantaneous, allowing the Flask web backend to render verdict metrics, confidence percentages, and breakdown vectors fluidly.

Conclusion

The study confirms that for domain-specific, localized classification tasks such as ad image moderation, a highly optimized convolutional network like YOLOv8n is vastly superior to large-scale vision transformers when deployed in bounded computing environments. By heavily augmenting a large-scale, cleanly split dataset of 8,000 images, the lightweight CNN achieved state-of-the-art accuracy, flawless memory conservation, and extremely fast inference latency.
